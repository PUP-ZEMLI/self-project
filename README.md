# KVON / Self Project

Статический портфолио-сайт без форм, базы данных и сторонних аналитических скриптов.

Основные стили разделены на `style.css` (база и раскладка) и `components.css` (компоненты, состояния и адаптивность). Код кейса АГС находится в отдельных `index.html`, `styles.css` и `script.js` внутри `cases/ags`.

## Локальный запуск

Требуется Node.js 20 или новее.

```bash
npm start
```

По умолчанию сайт доступен по адресу `http://127.0.0.1:5175`. Для другого окружения можно задать `HOST` и `PORT`.

## Проверка перед публикацией

```bash
npm run check
```

Проверка валидирует сервер и клиентский JavaScript, локальные ресурсы из HTML и CSS, уникальность `id`, отсутствие встроенных скриптов, небезопасной HTML-инъекции и ссылок `_blank` без `noopener`.

## Публикация

Можно публиковать весь каталог на любом статическом хостинге. Если используется `server.mjs`, он добавляет CSP и другие защитные заголовки, проверяет пути, поддерживает ETag, Brotli/Gzip и безопасно обслуживает только разрешённые файлы внутри проекта. На публичном домене обязательно включите HTTPS и перенесите защитные заголовки в настройки выбранного хостинга, если `server.mjs` там не используется.

Контактные карточки и ссылки в подвале подключены к Telegram, Instagram, VK, WhatsApp, Gmail и Mail.ru.
